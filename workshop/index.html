Политика конфиденциальности «Мастерская: провода и схемы»

Редакция от 26 октября 2026 года. Применяется к версии 1.0.1.

Разработчик — «Нореми». Контакт по вопросам игры и данных: Noremi.support@gmail.com.

Для версии 1.0.0 без рекламы действует прежняя политика. Обновление игры само по себе не означает согласия на рекламную обработку данных.

Игра и сохранения

Игра не требует аккаунта и не содержит покупок. Пройденные уровни, положение проводов, закреплённые подсказки, их баланс и сведения о начислениях, оформление, звук и выбор рекламы сохраняются в приватной области приложения на устройстве. Они нужны для продолжения игры и работы подсказок. Разработчик не получает игровые сохранения.

Облачной синхронизации нет; резервное копирование Android и перенос данных приложения отключены. Сохранения хранятся до удаления игры или очистки её данных в настройках Android. Сброс отдельной схемы не удаляет весь прогресс.

Добровольная реклама

В версии 1.0.1 используется Yandex Mobile Ads SDK 8.6.0 и один рекламный формат — реклама с вознаграждением. Просмотр начинается только по кнопке «+1 подсказка за рекламу». Подтверждённая рекламной сетью награда добавляет одну подсказку на баланс; её использование остаётся отдельным действием игрока.

Проходить уровни и использовать имеющиеся подсказки можно без рекламы и интернета. Объявления требуют подключения к сети. Баннеров, автоматических рекламных пауз между уровнями и отдельно подключённой аналитики разработчика нет.

До явного разрешения рекламы в игре рекламный SDK не инициализируется и приложение не запрашивает объявления. Отказ не закрывает доступ к уровням и имеющимся подсказкам.

Данные рекламного партнёра

После разрешения рекламы Яндекс обрабатывает технические сведения, необходимые для загрузки и показа объявлений, и сведения о рекламных событиях, включая подтверждение награды. Обработка происходит через рекламный SDK. Порядок обработки, сведения о получателях, хранении данных и правах пользователя приведены в политике конфиденциальности Яндекса и раскрытии данных Yandex Mobile Ads SDK.

В конфигурации этой игры отключены отслеживание местоположения и дополнительная рекламная аналитика приложения. Разрешение Android Advertising ID исключено. Для всех игроков включён режим ограниченной обработки данных, предназначенный для несовершеннолетней аудитории. Эти настройки не означают отсутствия любых технических идентификаторов или служебной обработки внутри SDK и его зависимостей. Таблица Яндекса описывает стандартную конфигурацию SDK; состав обработки зависит от настроек приложения.

Изменение выбора и удаление данных

В настройках игры можно выбрать «Без рекламы». После этого приложение прекращает новые рекламные запросы и показы. Уже инициализированный SDK может сохранять активность до перезапуска игры. Отказ не отменяет ранее выполненную передачу сведений рекламному партнёру.

Чтобы удалить локальный прогресс и настройки, можно удалить игру или очистить её данные средствами Android. Это действие не удаляет автоматически сведения, уже переданные Яндексу. По вопросам доступа, хранения и удаления данных рекламного партнёра используй порядок обращений, указанный в политике Яндекса. По вопросам самой игры можно написать разработчику на Noremi.support@gmail.com.

Внешние ссылки и обращения

Внешние политики открываются в браузере только по нажатию игрока. Браузер и сайт назначения обрабатывают сетевой запрос по своим правилам.

При обращении на Noremi.support@gmail.com разработчик получает сведения, которые пользователь включил в письмо, и использует их для ответа и решения вопроса по игре. Не присылай пароли, платёжные реквизиты и другие сведения, не нужные для обращения. Запросы об удалении переписки можно направить на тот же адрес.

Изменения политики

При изменении обработки данных политика и сведения в игре обновляются. Версия 1.0.0 сохраняет работу без рекламы. В версии 1.0.1 игрок отдельно выбирает, разрешать ли рекламу; установка обновления не заменяет этот выбор.
